# CrackedClient

A responsive static website for Vercel.

## Deploy
1. Extract this folder.
2. In Vercel, choose **Add New → Project** and import a Git repository containing these files, or use the Vercel CLI from this folder.
3. No build command or framework preset is needed; deploy as a static site.

## Add your client artwork
Put these image files in the `public/` folder (keep the exact filenames):
- `corz.png`
- `67.png`
- `gooba.png`

The page has built-in text fallbacks if an image is missing.

## Edit
All page content and styling are in `index.html`. Download URLs are external mirrors and open in a new tab.
