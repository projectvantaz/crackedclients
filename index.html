/ SETUP

Installation guide

A general guide to installing a .jar mod. Always follow the instructions for the specific client and Minecraft version.

01

Check the client requirements

Before downloading, check the client's official page or readme for its supported Minecraft version, mod loader, and required dependencies. Do not assume every client uses the same setup.

02

Download your chosen client

Return to the client library above and choose one of the download mirrors. The file should download from the selected third-party host.

03

Find your Minecraft mods folder

For the standard Minecraft launcher on Windows, open Run and enter %appdata%\.minecraft\mods. Other launchers may use a separate instance or profile folder.

04

Install the .jar file

Only if the client documentation says it is a compatible mod, place the .jar in the correct profile's mods folder alongside its required dependencies. Do not run an unknown .jar by double-clicking it.

05

Launch the matching profile

Start Minecraft using the exact game version and mod loader specified by the client creator. If it fails to load, remove the added file and check the creator's troubleshooting instructions.

Frequently Asked Questions

A few things to know before downloading.

Is this safe for my account?

DonutClients cannot guarantee how a third-party client behaves or whether it complies with a server's rules. Review the server rules and the original creator's information before using any client.

Which Minecraft version is supported?

Compatibility depends on the individual client. Check its download page or documentation for the supported Minecraft version and mod loader before installing.

Are these files actively maintained?

Maintenance is controlled by each original client creator. This site is a link directory and does not control releases or updates.

Are the files secure?

Files are hosted externally and have not been independently audited by this website. Scan each download with reputable security software and do not open files you do not trust.

Why are there two download buttons?

Each listed client has two external download mirrors. If one host is unavailable, you can try the other. Both links lead away from DonutClients.
